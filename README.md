# GraphRAG Research Notebook

> A hybrid Retrieval-Augmented Generation (RAG) and Knowledge Graph system built using strict free-tier and open-source tools for research, document exploration, and multi-hop reasoning.

---

## 📌 Project Goal (2-3 Sentences)
The GraphRAG Research Notebook combines vector similarity search with structured knowledge graph traversal to answer complex, multi-hop questions over academic and technical research documents. By leveraging a hybrid retriever, the system retrieves both semantic passage embeddings and entity-relationship subgraphs to feed grounded context into an LLM. Designed as a B.Tech AI mini-project, it demonstrates enterprise-grade GraphRAG architecture operating entirely within free-tier and open-source constraints.

---

## 🛠️ Tech Stack & Tool Choice Rationale

| Layer | Selected Tool / Library | Tier | Why Chosen? |
| :--- | :--- | :--- | :--- |
| **Backend Framework** | **FastAPI** | Open Source | High performance, asynchronous Python web framework with auto-generated OpenAPI documentation. |
| **Orchestration** | **LangChain** | Open Source | Standardized ecosystem for composing vector stores, graph retrievers, and LLM prompt pipelines. |
| **LLM Inference** | **Gemini 2.5 / 3 Flash API** | Free Tier | Google's high-speed, long-context LLM with a generous free-tier allocation via Google AI Studio. |
| **Embeddings** | **sentence-transformers** (`all-MiniLM-L6-v2`) | Open Source (Local) | Fast, lightweight 384-dimensional dense vector embedding model running locally without API costs or rate limits. |
| **Vector Store** | **ChromaDB** | Open Source (Local) | Embedded, serverless vector database requiring no external service setup; stores passage vectors directly on disk. |
| **Graph Store** | **Neo4j AuraDB Free** | Free Tier | Cloud-hosted graph database providing native Cypher query execution for entity-relationship retrieval. |
| **Benchmark Dataset** | **HotpotQA (distractor subset)** | Public / HF | Standard multi-hop question answering dataset containing bridge & comparison questions with distractor paragraphs. |
| **Testing & Quality** | **pytest** | Open Source | Unit and integration testing framework for verifying schemas, loader pipelines, and API endpoints. |

## 🚀 Setup & Execution Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/graphrag-research-notebook.git
cd graphrag-research-notebook
```

### 2. Set Up Virtual Environment & Install Dependencies
```bash
python -m venv venv

# On Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# On Linux / macOS:
source venv/bin/activate

# Install required dependencies
pip install -r requirements.txt
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your free-tier API keys:
```bash
cp .env.example .env
```
Key required credentials:
- `GEMINI_API_KEY`: Obtain from [Google AI Studio](https://aistudio.google.com/) (Free Tier).
- `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`: Obtain from [Neo4j AuraDB Free](https://neo4j.com/cloud/platform/aura-graph-database/).

### 4. Run the Dataset Loader & Generate Local Sample
Download HotpotQA distractor dataset and save the 200-record local iteration sample:
```bash
python -m data_loading.loader
```

### 5. Inspect Dataset Statistics
Run the stats script to display benchmark breakdown and sample entries:
```bash
python -m data_loading.stats
```

### 6. Run Sanity Test Suite
Execute unit tests to verify dataset loading and schema validation:
```bash
pytest tests/
```

### 7. Launch FastAPI Server
Start the local FastAPI development server:
```bash
uvicorn api.main:app --reload
```
Navigate to `http://127.0.0.1:8000/docs` in your browser to view the interactive API documentation and test the `/health` endpoint.
